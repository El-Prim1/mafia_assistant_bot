# 🎭 Mafia Helper Bot

Telegram-бот на **Python** и **aiogram 3**, созданный для помощи игрокам в онлайн-мафии.

Бот не является ведущим и не управляет самой игрой. Его задача — ускорять рутинные действия игрока и упрощать работу с игровой информацией.

## 🚀 Возможности

### 🦹 Лже-вскрытия

Помогает быстро создавать фальшивые вскрытия с использованием готовых шаблонов и автоматической подстановкой имён игроков.

### 📋 Работа со списками

Позволяет создавать и обрабатывать списки игроков на основе дампа игрового стола, избавляя от необходимости вручную переписывать данные.

### ⚖️ Помощник адвоката

Предоставляет инструменты для фильтрации и обработки списков, помогая адвокату быстрее работать с игровой информацией.

## 🛠 Используемые технологии

* Python
* aiogram 3
* FSM для пошаговых сценариев
* Telegram-клавиатуры
* Парсинг пользовательского текста
* Шаблоны для генерации игровых сообщений
* Middleware для обработки и очистки сообщений

## 📌 Назначение

Основная цель проекта — автоматизировать повторяющиеся действия во время онлайн-партий в мафию и сделать работу игрока со списками, игровыми данными и текстовыми шаблонами быстрее и удобнее.

> Бот помогает игроку работать с информацией, но не играет вместо него.
